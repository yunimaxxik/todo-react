# 📝 Todo App — персональный менеджер задач

## 🎮 О проекте

**Todo App** — это современное, легкое и интуитивно понятное веб-приложение для управления повседневными задачами. Оно спроектировано для того, чтобы помогать структурировать дела, отслеживать прогресс выполнения и эффективно достигать поставленных целей. 

Интерфейс построен на базе компонентного подхода с использованием реактивного обновления данных. Приложение полностью типизировано с помощью **TypeScript**, что обеспечивает высокую надежность кода, автодополнение на этапе разработки и минимизацию ошибок в рантайме.

### 🔥 Ключевые возможности

* **Управление задачами**: быстрая генерация новых записей с автоматическим назначением уникальных идентификаторов (`id`).
* **Интерактивный контроль**: удобная отметка завершенных дел с помощью реактивных чекбоксов.
* **Мгновенное удаление**: быстрая очистка списка от неактуальных или ошибочно добавленных задач.
* **Умная навигация**: функция быстрого переключения и автоматической фокусировки на первой еще не выполненной задаче.
* **Аналитический счетчик**: наглядный интерактивный индикатор, который в реальном времени отображает количество выполненных и оставшихся задач.
* **REST API (Mock Бэкенд)**: полноценная интеграция с сервером базы данных для синхронизации, сохранения и контроля состояния всех todo-записей.

## 🛠 Технологический стек

Проект разработан с использованием самого актуального стека фронтенд-разработки:

* **React** — библиотека для построения пользовательских интерфейсов (функциональные компоненты, хуки, `StrictMode`).
* **TypeScript** — строгая типизация для повышения надежности, безопасности и читаемости кодовой базы.
* **Vite 8** — сверхбыстрый инструмент сборки нового поколения, оптимизированный под работу с TypeScript и ESM.
* **Sass / SCSS** — модульная стилизация интерфейса с использованием переменных и методологии **БЭМ**.
* **json-server** — локальный REST-сервер для симуляции бэкенда и долгосрочного хранения данных.
* **JSON5** — современный формат хранения базы данных с поддержкой комментариев.
* **ESLint**  — статическая проверка качества кода и соблюдения архитектурных стандартов.
